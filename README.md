# 此地无银三百两 · SanBaiLiang

一个完全本地运行的记账应用：**Android 端 + Windows 桌面端**。账目、余额与 AI 密钥只保存在本机，两端通过手动导入/导出 JSON 账本文件同步（含余额与删除）。

> 界面中的 q 版装饰贴图由 AI 生成，非官方素材，详见「界面贴图」一节。

## 功能

- **快速记账**：金额键盘、支出/收入切换、自定义日期与备注
- **可自定义分类**：内置吃、用、玩、学、出行、其他，可改名、换图标、新增或删除；分类改动会随账本同步到另一端
- **自动记账**：监听微信、支付宝、云闪付、数字人民币、各大银行 App（工商/建设/农业/中国/交通/邮储/中信/光大/民生/浦发/平安/兴业等）、手机钱包与购物平台的通知，并解析银行短信；同一类型同金额 10 分钟内疑似重复会标红提醒
- **限额提醒**：月限额、日限额、离日限额还有多少元提醒；支出达到月限额 25% / 50% / 75% 且进度快于日期时，AI 提示开销过大
- **批量操作**：长按多选，批量删除或设置「不计入当日限额 / 不计入限额」
- **统计**：日 / 周 / 月 / 年 / 自定义区间的收支与分类占比
- **资产**：以「余额锚点 + 基准日后净收支」计算当前总余额，可随时重新核对；余额分为**总余额（大板块）**、**攒着 / 可用（小板块）**，三者可随时手动调整
- **自动攒着**：按每周 / 每月 / 每年自动把可用的一部分转入攒着，可用不足时跳过该期，错过的周期逐期补足；可开关「视作支出」以计入日/月限额与统计。全程只做账面划分，不涉及真实资金搬动
- **AI 个性评价**：使用自备 DeepSeek API Key 生成明细页点评，密钥仅存本机
- **MCP 接口（仅电脑端）**：AI Agent 可通过 MCP 直接查询/设置总余额与攒着/可用、配置自动攒着、记账改账删账、管理分类、读取支出统计图表、导入导出账本同步文件，详见 [MCP调用指南](MCP调用指南.md)
- **双端同步**：两端各自维护账本文件，导入只合并、不覆盖；`syncId` 去重 + `updatedAt` 最后写入胜出，删除通过墓碑标记跨端传播

## 工程结构

| 模块 | 说明 |
| --- | --- |
| `app/` | Android 应用，Kotlin + Jetpack Compose + Room |
| `sync/` | 两端共享的同步协议、固定分类与合并规则（纯 Kotlin/JVM） |
| `desktop/` | Compose Desktop 桌面端，打包为 Windows amd64 app-image |

## 构建

要求：JDK 17、Android SDK 35。

```bash
# Android 发行 APK
./gradlew :app:assembleRelease

# Windows 桌面端（输出到 desktop/build/compose/binaries/main/app/MucageLedger）
./gradlew :desktop:packageAppImage
```

签名配置从本机 `local.properties` 读取（该文件已被忽略，不会进入仓库）：

```properties
RELEASE_STORE_FILE=release.jks
RELEASE_STORE_PASSWORD=你的口令
RELEASE_KEY_ALIAS=mucage
RELEASE_KEY_PASSWORD=你的口令
```

本机没有 keystore 时会构建未签名的发行包，方便直接 clone 后编译调试。

## 两端同步

1. 手机「设置 → 数据同步 → 导出到文件」，得到 `此地无银三百两-账本-*.json`
2. 把文件传到电脑，桌面端「设置 → 打开并合并手机账本」，或直接用文件参数启动：
   `MucageLedger.exe "此地无银三百两-账本-20261031-1200.json"`
3. 电脑端账目会自动保存到自己的 `%APPDATA%\MucageLedger\ledger.json`，导入不会改动手机导出的文件
4. 在电脑上增删改账目、设置余额后，在「设置 → 导出给手机」另存一个新文件
5. 把新文件传回手机，在「设置 → 数据同步 → 从文件导入」，合并结果会显示新增/更新/跳过数量

如果导入后发现「本机另有 N 笔未在对方文件中」，说明另一端也有新记账，按提示反向导出一次即可两端一致；两端独有的账目都会保留，不会被覆盖。

删除不会立即跨端生效，而是留下删除墓碑；下一次导入时另一端会同步删除。余额以基准日与 `updatedAt` 较新的锚点为准，攒着金额与自动攒着配置也随余额一起同步。

「攒着」与「可用」只是账面上的划分，不会真实转移资金。自动攒着由手机和电脑各自在打开时补算，依靠同步的结算时间防重复；两端都升级到 10.27.3 及以上才能完整同步这些字段。

## MCP 接口（电脑端）

桌面端内置 MCP stdio 服务，供支持 MCP 的 AI 客户端调用：

```bash
MucageLedger.exe --mcp
```

可查询总余额/攒着/可用、设置总余额、调整攒着与可用、配置自动攒着、增删改账目、管理分类、读取支出统计、导入导出账本同步文件。完整工具参数与客户端配置见 [MCP调用指南](MCP调用指南.md)。使用前请先关闭桌面窗口，避免与界面同时写入账本。MCP 服务运行时会在 Windows 通知区域显示绿色 ¥ 托盘图标，可查看 PID 或手动停止。

如果客户端只允许 `python` / `node` 等解释器命令（例如 AstroBot），用随包附带的 `mucage_mcp.py` 作为启动器：

```json
{"mcpServers":{"mucage-ledger":{"command":"python","args":["D:\\MucageLedger\\mucage_mcp.py"]}}}
```

## 隐私与数据

- 账目、余额、API Key 均只保存在设备本地，不上传任何服务器
- 仓库中不包含账本数据、签名密钥或 API 密钥
- 同步文件由用户自行传输，不经过第三方服务
